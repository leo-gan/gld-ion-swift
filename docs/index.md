# gld-ion-swift

gld-ion-swift is an [Amazon Ion](https://amazon-ion.github.io/ion-docs/) serializer
written in Swift. The runtime and the code generator are Swift. They do not
wrap ion-c, ion-java, ion-swift, or any other C, C++, or Rust Ion library.
